# SCNN
Projekt nr 1, realizowany w ramach kursu "Sieci Neuronowe" lato 2025/2026 na Politechnice Wrocławskiej W13.

## Temat: Lekkie sieci splotowe i optymalizacja modeli

Zaimplementuj i porównaj lekkie architektury sieci splotowych (np. MobileNet, ShuffleNet, SqueezeNet) dla wybranego zadania klasyfikacji obrazów. Przygotuj dataset oraz przeprowadź trening modeli w porównywalnych warunkach. Oceń modele zarówno pod względem jakości (np. accuracy), jak i wydajności obliczeniowej (liczba parametrów, FLOPs, czas inferencji, zużycie pamięci). Przeanalizuj kompromis pomiędzy dokładnością a efektywnością modeli. Zastosuj techniki kompresji, takie jak pruning lub quantization, i zbadaj ich wpływ na właściwości modeli. Porównaj wyniki przed i po optymalizacji. Sformułuj wnioski dotyczące projektowania efektywnych modeli dla urządzeń o ograniczonych zasobach.
